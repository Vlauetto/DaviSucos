## 📖 Sobre o Projeto

O *Davi Sucos* é uma aplicação web desenvolvida para apresentar os produtos da marca, compartilhar informações sobre a empresa e facilitar o atendimento aos clientes através do WhatsApp.

O projeto foi construído utilizando *React + Vite*, oferecendo uma navegação rápida, moderna e responsiva.

---

## ✨ Funcionalidades

- 🏠 Página Inicial
- 🍍 Catálogo de Produtos
- 👨‍👩‍👦 Página Sobre Nós
- 📞 Página de Contato
- 💬 Botão de pedido via WhatsApp
- 📱 Layout responsivo

## 🚀 Como Executar o Projeto

### Clone o repositório

bash
git clone https://github.com/seu-usuario/DaviSucos.git


### Acesse a pasta

bash
cd DaviSucos


### Instale as dependências

bash
npm install


### Execute o projeto

bash
npm run dev


O projeto estará disponível em:

bash
http://localhost:5173
